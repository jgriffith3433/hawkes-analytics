Hawkes Analytics

Your first event in three steps. This page runs the real SDK in debug mode and reports to the hawkes-analytics product; opt out below to stop it. SDK: loading…

1 Add the script

One line in your page's <head>. It starts sessions, page views, errors and load timings by itself. Add data-product="your-game" and it sends them to Hawkes Studio's Analytics tab.

HTML
<script src="https://hawkesgen.ai/sdk/analytics@1.js" data-product="your-game" async></script>

2 Send an event

Call the SDK where something happens in your game. Press a button to run its line.

JavaScript
hawkesAnalytics.levelStart(1);
hawkesAnalytics.death('spikes');
hawkesAnalytics.levelEnd(1, 'complete');
hawkesAnalytics.track('demo_click');

Or send one event all the way to Hawkes Gen and see it come back acknowledged. This one is not kept for any player; it only proves the road is open.

Batching

Events are not sent one by one. A burst goes out as one request 2 seconds after its last event; when you hide the page, anything waiting goes at once. Tap the button five times fast and watch the count: it goes up by one.

Clicks: 0 · requests carrying your clicks: 0 · waiting to be sent: 0

    Offline and reliability

    With a product set, events that cannot be sent (you are offline, or the server is down) wait in this browser, at most 40 batches, and go out when it comes back online or on your next visit. No retry timer runs. The tests cover it.
