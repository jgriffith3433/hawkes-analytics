Your first event in three steps. This page runs the real SDK in debug mode with no product, so events stay here and nothing is sent. SDK: loading…

1 Add the script

One line in your page's <head>. It starts sessions, page views, errors and load timings by itself. Add data-product="your-game" and it sends them to Hawkes Studio's Analytics tab.

<script src="https://hawkesgen.ai/sdk/analytics@1.js" data-product="your-game" defer></script>

2 Send an event

Call the SDK where something happens in your game. Press a button to run its line.

hawkesAnalytics.levelStart(1);
hawkesAnalytics.death('spikes');
hawkesAnalytics.levelEnd(1, 'complete');
hawkesAnalytics.track('demo_click');

Or send one event all the way to Hawkes Gen and see it come back acknowledged. This one is not kept for any player; it only proves the road is open.

Offline and reliability

With a product set, events that cannot be sent (you are offline, or the server is down) wait in this browser, at most 40 batches, and go out when it comes back online or on your next visit. No retry timer runs. This demo has no product, so nothing waits here; the tests cover it.
