# Hawkes Analytics for Unity

Player analytics for Unity WebGL games. Create Assets > Create > Hawkes > Analytics Settings, save it as
`Assets/Resources/HawkesAnalyticsSettings.asset` with your project's product, and call `HawkesAnalytics.LevelStart`,
`Death`, `LevelEnd`, `Track`, `Feedback` or `Ask` from the game. It loads Hawkes Gen's SDK into the page by itself.

Docs: https://github.com/jgriffith3433/hawkes-analytics#unity
